Um projeto desenvolvido na faculdade

Burguer Donalds — Totem de Autoatendimento

Projeto acadêmico

Prototipagem funcional de um sistema de autoatendimento para uma hamburgueria fictícia, desenvolvido para permitir que o cliente escolha produtos e monte seu pedido por meio de uma interface de totem.

Problema

A proposta foi criar uma alternativa de autoatendimento para uma hamburgueria, permitindo que o cliente consulte os produtos e organize seu pedido sem depender de um atendente durante a escolha.

O que eu fiz

Desenvolvi uma prototipagem funcional de um totem com tela inicial, catálogo de produtos com imagens e preços, seleção de itens, carrinho de compras, finalização do pedido e simulação de pagamento.

Como eu fiz

Utilizei HTML para estruturar a página, CSS para desenvolver a parte visual e JavaScript para implementar as funcionalidades e as interações do sistema.

Resultado

Foi desenvolvida uma prototipagem funcional que atende aos requisitos propostos para o projeto. A atividade proporcionou experiência prática com desenvolvimento web e com a utilização conjunta de HTML, CSS e JavaScript.
